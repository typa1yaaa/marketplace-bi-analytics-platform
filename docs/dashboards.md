# Дашборды в Superset

После `make superset` откройте http://localhost:8088 (логин: `admin`, пароль: `admin`). 
Подключение к БД `marketplace` создается автоматически.

## Структура дашборда

Дашборд организован в виде трех вкладок, каждая из которых отвечает на конкретный вопрос:

### Вкладка 1: Обзор бизнеса
"Что происходит с бизнесом?"

- **Big Number:** GMV за 7 дней (7.27M) с трендом
- **Big Number:** Конверсия в контакт за 7 дней (7,94 %)
- **Line Chart:** Динамика GMV по дням
- **Line Chart:** Количество завершенных сделок по дням
- **Bar Chart:** GMV по категориям и неделям

<img src="img/overview.jpg" alt="" width="700"/>

### Вкладка 2: Воронка и атрибуция
"Где теряем клиентов?"

- **Funnel Chart:** Воронка конверсии (Impressions - Views - Contacts - Deals)
- **Line Chart:** Конверсия в контакт по категориям. **Падение Electronics видно с 15 сентября.**
- **Table:** Атрибуция потерь по сегментам. **Electronics объясняет 100% потерь.**

<img src="img/funnel.jpg" alt="" width="700">

### Вкладка 3: Надежность данных
"Можно ли доверять отчету?"

- **Table:** Качество загрузки данных (`raw_rows`, `staged_rows`, `status = ok`)
- **Line Chart:** Объем данных относительно 7-дневной базы (коридор 0.6–1.6)
- **Table:** Обнаруженные аномалии с z-score. **Electronics: z = -4.42 (15 сентября)**
